# Same Information, Different Generalization: Representation Sensitivity in Neural Network Regression

This repository contains the experiments, results, analyses, and figures for the paper. The experiments study how invertible feature transformations affect finite-sample regression performance, comparing neural networks with XGBoost and TabICLv2.

## Repository structure

| Directory | Contents |
| --- | --- |
| `experiments/` | Python scripts and Jupyter notebooks for generating synthetic data, running experiments, and computing transformation summaries. |
| `results/` | Outputs from the experiments, including Excel workbooks and CSV files containing model performance, diagnostics, and transformation summaries. |
| `analysis/` | R code that reads the experiment results, performs the statistical analyses, and generates the figures. |
| `figures/` | Figures generated by the R analyses and used in the paper. |

## Workflow

1. Run the relevant Python script or notebook in `experiments/` to generate the corresponding outputs in `results/`.
2. Use the R code in `analysis/` to read and analyze those outputs.
3. Save the resulting plots in `figures/`.

The experiment files cover matched-nonlinearity comparisons, population standardization, quantile preprocessing, alternative learners, optimization and capacity sweeps, active and inactive predictor controls, error localization, and Yeo–Johnson holdout experiments. The quadrature and curvature notebooks compute the transformation summaries used in the analyses.

## Running experiments

Run the Python scripts with `experiments/` as the working directory, since most scripts save to `../results/`. Experiment settings, such as sample size, repetitions, transformation strengths, and output filenames, are defined within each script. Check these settings before running a different configuration and give its output a distinct filename.

The experiments generate their synthetic data directly. Python dependencies vary by experiment and include NumPy, pandas, SciPy, scikit-learn, XGBoost, PyTorch, and TabICL. Use the repository's recorded environment information to reproduce the software versions used for the reported results.

The saved outputs in `results/` can also be used directly with the R analyses without rerunning model training.
